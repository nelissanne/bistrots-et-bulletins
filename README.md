# bistrots-et-bulletins
Projet Python de deuxième année de l'Ensae. L'objectif est de confronter au niveau national le nombre de bar-tabacs dans les communes et les résultats des élections municipales. Ce projet s'inspire de l'étude « Quand les bars-tabacs ferment : l'érosion du lien social local et la progression du vote d'extrême droite en France » d'Hugo Subtil.
